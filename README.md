# 📝 Reflection

This activity helped me understand how algorithmic efficiency affects the performance of a program. While solving the five HackerRank problems, I practiced different concepts such as matrix traversal, dynamic arrays, string manipulation, comparison operations, and frequency mapping. I learned that solving a problem correctly is not enough; the solution should also use appropriate time and space complexity. For example, problems involving repeated string searches can become inefficient if every query is compared with every input string. Using frequency mapping can reduce unnecessary repeated operations. Similarly, understanding matrix indexing helps in efficiently calculating diagonal values without using unnecessary additional memory. Implementing the solutions in Python also improved my understanding of lists, strings, loops, and dictionaries. HackerRank provided an opportunity to test the solutions against multiple test cases and verify their correctness. Maintaining the solutions in GitHub helped me organize my work and build a portfolio that demonstrates my programming and problem-solving practice.
